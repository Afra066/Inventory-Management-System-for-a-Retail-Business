
# Inventory Management System for a Retail Business

A web-based Inventory Management System developed to manage retail business operations efficiently.

## Technologies Used

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Main Modules

- Dashboard
- Product Management
- Customer Management
- Supplier Management
- Invoice Management
- Expense Management
- Reports
- User Management

## Development Tools

- Visual Studio Code
- XAMPP
- Git and GitHub

HNDIT Final Year Project

Developed as part of the Higher National Diploma in Information Technology (HNDIT) at SLIATE.
